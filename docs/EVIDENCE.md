## 2. 如何快速审计

```bash
# 提交总量与粒度
git log --oneline | wc -l
git log --stat --oneline | head -60

# 逐条查看某次提交的完整改动
git show 3105780

# 搜索某条设计决策是什么时候进入代码的
git log -S"allocateScores" --oneline

# 确认没有密钥进入版本库
git log --all -S"sk-" --oneline
git ls-files | grep -i "\.env$" || echo "no .env tracked"
```

| 故障 | 现象 | 根因 | 落点 |
|---|---|---|---|
| SSE 自杀 | 流只发出一个事件就中断 | 用 `request.close` 判断客户端断开 | `f634f25` |
| 空响应 | 简答题批次返回空内容，整卷失败 | 推理吃光输出预算 | `cbac5fc` + `06698be` |
| 生产白屏 | `npm start` 打开是一片白 | `@fastify/static` 关掉 wildcard | `f634f25` |
