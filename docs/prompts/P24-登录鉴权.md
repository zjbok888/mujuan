# P24 · 账号密码登录（核心迭代 2）

## 我的 Prompt
> 要在一个登录页面实现双端口登录，学生端要有账号密码，教师端也是。

## AI 的第一版方案（有缺陷）
把 `{username, password}` 直接在前端比对，登录态放 localStorage。
否掉理由：**前端比对等于没有鉴权**，任何人改 localStorage 就能进。

## 引导修正
> 密码要哈希存储，会话用 httpOnly Cookie，服务端每个接口都要校验。
> 学生账号由老师创建，不开放自助注册。

## 落地
- `scrypt` 加盐哈希（Node 内置，不新增依赖）；
- 会话内存表 + httpOnly Cookie，12 小时过期；
- 所有 `/api` 走 `onRequest` 钩子：未登录 401，角色不符 403；
- 身份从会话取，**忽略请求体里的 `student`**——否则可以冒充他人交卷；
- 教师端「成员」页建学生账号。

## Bug 与修复
- 登录后白屏：`React error #310`——我把提前 return 放在 `useCallback` 之前，
  登录前后 hook 数量不一致。修法：所有 hook 移到 return 之前。
- 跨端 Cookie 串台：老师登录后打开学生端，页面在但接口全 403。
  修法：比对会话角色与端口角色，不符则主动登出并提示。
