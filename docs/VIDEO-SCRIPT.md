# 演示视频分镜（7 分钟 · MP4 1080p）

> 目标：前 3 分钟让评委相信这东西能用，中间 2.5 分钟让评委相信是你指挥 AI 做出来的，
> 最后 1.5 分钟让评委相信他能自己复现。

## 录制前准备

```bash
npm run build
npm start                    # 终端 A：生产模式，端口 4000
npm run seed                 # 终端 B：灌入 12 份作答
```

浏览器窗口 1440×900，缩放 100%，提前打开三个标签页：

1. `http://127.0.0.1:4000/?demo=1#/`（一键演示）
2. `http://127.0.0.1:4000/#/paper/<paperId>`（试卷页）
3. `http://127.0.0.1:4000/#/stats/<paperId>`（学情页）

终端窗口调大字号（16pt+），录屏软件开启 1080p / 30fps。

## 分镜

### 0:00–0:35 痛点

- 画面：教师桌面上摊开的 Word 试卷、微信群里的"这周出一套导数题"。
- 旁白：*"出卷是老师每周都要做的事：找题、改题、配分、排版、再算一遍总分。一套 45 分钟的卷子，两小时。"*
- 落点：**墨卷：用一句话描述这节课教了什么。**

### 0:35–3:00 完整闭环演示

| 时间 | 动作 | 讲解要点 |
|---|---|---|
| 0:35 | 打开 `?demo=1` | "打开即演示，不需要任何 Key" |
| 0:45 | 停在思考流面板 | "模型先读大纲、识别考点、拉开难度梯度——这一步是真的在推理" |
| 1:00 | 蓝图卡片出现 | "它给出的是一份**命题蓝图**，不是页面代码" |
| 1:20 | 题目逐张落地 | "每落地一题，系统的校验器就同时在工作" |
| 1:50 | 校验状态条转绿 | "分值合计、答案是否落在选项内、细则分值和、题干查重，八条规则" |
| 2:00 | 打开试卷页，改一道题的分值 | "老师可以改，改完立刻重新校验——总分对不上会当场提示" |
| 2:20 | 发布 → 试答 → 交卷 | "学生作答后是**确定性评分**，同一份卷子永远同样的分" |
| 2:40 | 学情页 | "知识点正确率、失分题榜，全部来自刚交的那批卷子" |
| 2:55 | 打印预览 | "直接出 A4，公式不跑版" |

### 3:00–5:30 AI 协同过程复现（硬性要求 ≥2 分钟）

这一段**必须现场操作**，不要事后补拍。

**3:00–4:10 现场演示一次 Prompt 驱动的模块生成**

- 切到编辑器，打开 `server/prompts/index.ts` 与 `shared/ir.ts`。
- 口述当时的指令（可对照 `docs/prompts/P02-流式客户端.md`）：
  > "我要一个只负责出题的模块。约束是：不许改分值、不许改题型，分值由系统按权重分配；
  > 输出必须是 JSON；如果校验不过，把错误清单回喂给它修，最多两轮。"
- 展示 AI 首版方案里的一处问题（`answers` 限 300 字符），
  再展示真实数据如何把它打回（终端里的 `too_big` 报错）。

**4:10–5:10 现场复现一个顽固 Bug**

- 打开 `server/routes/papers.ts`，定位到 `res.on('close', ...)` 那一行。
- 展示错误版本 `request.raw.on('close', ...)`，说明现象：
  *"SSE 只发出一个事件就断了"*。
- 讲清根因：*"Node 的 request 在请求体读完时就触发 close，我用它判断断连，等于每个请求开头自杀。"*
- 展示 `npm run verify` 里新增的那条断言——**修完之后先加检查，再加功能**。

**5:10–5:30 提交历史**

- 终端执行 `git log --oneline`，快速滚动 17 条提交。
- 打开一次 `git show`，指出提交体里的 `Prompt-ID` 尾注。

### 5:30–6:30 架构与约束

- 一页图（可直接用技术文档第 3 节的分层图）：
  `routes → domain → shared`，`infra` 注入。
- 三句话讲完：
  1. AI 只产出 IR，不产出页面代码；
  2. 不变量（分值、题型、总分）由系统持有，模型改不动；
  3. 模型输出一律当不可信数据，先过 zod 再过业务规则。

### 6:30–7:00 复现

- 干净目录，依次执行：

```bash
npm install
npm run build
npm run verify     # 9/9 passed
npm start
```

- 收尾字幕：**"评委只需要这三条命令。"**

---

## 注意事项

- 全程不要出现真实 API Key（终端里 `.env` 不要 `cat`）。
- 演示模式响应很快，如果要展示"流式感"，把 `DEMO_STEP_MS=120` 后重启服务。
- 录制"AI 协同"段落时，把与 AI 的对话窗口也录进去（分屏或画中画），这是赛题明确要求的形式。
